Claude로 하는 수학 문제 만들기

본 연수 시간 밖에서 더 해 볼 수 있는 활용 사례입니다. 첫 번째는 이미지로 된 수학 문제를 한글 파일로 받고, 유사 문제까지 뽑는 방법입니다. 이어서 수학 교사에게 도움이 되는 사이트를 소개합니다.

오른쪽 화살표 키, 아래 버튼, 화면 좌우 밀기로 넘길 수 있습니다.

+

1이미지 문제를 한글 파일로, 그리고 유사 문제까지

문제집이나 기출 문제를 사진·캡처로만 가지고 있을 때 쓰는 방법입니다.

① 올리기이미지문제를 캡처하거나 촬영한 이미지를 Claude에 올립니다.
② 한글 변환hwpx문제·정답·풀이를 한글 파일로 받습니다. 수식은 한글 수식으로 들어갑니다.
③ 유사 문제hwpx같은 유형으로 숫자와 조건을 바꾼 문제를 정답, 풀이와 함께 받습니다.
받은 파일은 한글에서 바로 열어 고칠 수 있습니다. 수식을 더블클릭하면 수식 편집기가 열립니다.

2Claude에게 이렇게 요청합니다

문제 이미지를 올린 뒤, 두 번에 나누어 요청합니다. 아래 문장은 예시이므로 상황에 맞게 고쳐 씁니다.

1이미지 문제를 hwpx 파일로
이 이미지에 있는 수학 문제를 hwpx 파일로 만들어줘.
수식은 전부 한글에서 사용하는 수식으로 입력해줘.
정답과 풀이도 문제 아래에 같이 넣어줘.
넣을 것문제가 보이는 이미지 파일. 여러 문제면 한 번에 올려도 됩니다.
2유사 문제 만들기
이 문제와 같은 유형의 유사 문제를 3개 만들어줘.
같은 형식의 hwpx 파일로 만들고, 정답과 풀이도 넣어줘.
풀이는 한 번 검산해서 맞는지 확인해줘.
고칠 곳문제 수, 난이도, 바꿀 조건(숫자만, 도형까지 등)을 원하는 대로 바꿉니다.

Claude가 만든 파일 (한글 hwpx)

⬇원문제 · 이미지에서 옮긴 문제, 정답, 풀이hwpx · 8KB ⬇유사 문제 3개 · 정답, 풀이 포함hwpx · 10KB

파일 모양

문제 하나가 표 하나로 들어가 있습니다. 위 칸에 단원과 유형, 가운데 칸에 출처, 아래 칸에 문제와 정답, 풀이가 있습니다.

유사 문제 표시

유사 문제에는 출처 칸에 자체 제작이라고 적혀 있어서, 원문제와 구분됩니다.

교사가 꼭 확인할 것
정답과 풀이를 그대로 믿지 말고 직접 한 번 풀어 봅니다. 세 번째 유사 문제처럼 다른 방법으로 검산해 달라고 하면 틀릴 가능성이 줄어듭니다.
수식이 원문제와 같은지, 조건이 빠지지 않았는지도 한글에서 열어 확인합니다.

쓰는 법

메뉴

7수학몬 인수분해 배틀

인수분해를 게임처럼 연습하는 배틀형 웹 게임입니다.

게임 방식

시작 수학몬(불·풀·물)을 고르고 야생의 수학몬과 배틀합니다. 화면에 나온 다항식(예: x² + 5x + 6)을 키패드로 인수분해해 입력하면 공격이 됩니다.

설정

중학교·고등학교를 고르고, 난이도는 쉬움, 보통, 어려움, 무한 중에서 정합니다. 한글과 영어 전환 버튼도 있습니다.

알아 둘 것

  1. 제곱은 ^2로 입력하라고 안내됩니다.
  2. 힌트와 난이도 하락 기능이 있습니다.
  3. 끝나면 걸린 시간, 푼 문제 수, 문제당 평균 시간 등 결과 화면이 나옵니다.
수업에서는 인수분해 단원의 마무리 연습이나 남는 시간 활동으로 쓸 수 있습니다. 결과 화면의 문제당 평균 시간을 학생끼리 비교하지 않도록 안내하면 좋습니다.
